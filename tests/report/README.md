# Development Pipeline and Model Evaluation Reports

This folder contains a source-readiness matrix for the 14 development phases. It is not a model-results report. Model results and diagrams are generated by `scripts/evaluate.py` from actual predictions exported by a model.

## Contents

- `development_pipeline_matrix.py`: audits expected files for each development phase.
- `output/`: generated source-readiness report. It contains no model-performance scores.

## Generate the pipeline readiness report

```bash
cd /home/rousan-pc/Collage Resume/project/Multimodal-Sentiment-Derivation
python3 tests/report/generate_reports.py
```

This writes `development_pipeline_matrix.md` and `.csv`. It does not evaluate a model or claim model performance.

## Evaluate a model

`scripts/evaluate.py` evaluates predictions that were actually produced by a model and saved as CSV. There must be one row for every sample in the chosen manifest split. The CSV schema is:

```bash
python3 scripts/evaluate.py \
  --manifest data/processed/processed_manifest.json \
  --predictions /path/to/test_predictions.csv \
  --checkpoint /path/to/model.pth \
  --model-name "experiment-001" \
  --split test
```

Required emotion columns use the manifest emotion names, for example:

```csv
sample_id,emotion_probability_Curiosity,emotion_probability_Uncertainty,emotion_probability_Excitement,emotion_probability_Happiness,emotion_probability_Surprise,emotion_probability_Disgust,emotion_probability_Fear,emotion_probability_Frustration
clip_001,0.82,0.21,0.63,0.91,0.14,0.02,0.03,0.11
```

Optional outputs are `predicted_valence` in `[1, 7]` and the complete set of `sentiment_probability_Negative`, `sentiment_probability_Neutral`, and `sentiment_probability_Positive` (each row must sum to 1). The evaluator matches by `sample_id`, rejects missing/extra IDs, and loads the ground truth from the requested manifest split.

Outputs include per-emotion F1/precision/recall/ROC-AUC, micro/macro/weighted F1, hamming loss, exact-match accuracy, per-emotion confusion matrices, and F1 charts. Optional outputs include a sentiment confusion matrix and valence regression MAE/RMSE/R² and scatter plot. Reports record SHA-256 hashes for the manifest, predictions, and optional checkpoint for traceability; hashes do not independently prove predictions came from that checkpoint.

Important: this repository still has no implemented training/inference pipeline, trained checkpoint, or local raw EmoReact media. Therefore it cannot produce genuine model predictions yet. Do not populate the prediction CSV with hand-written, random, or example scores; run the trained model on the held-out split first. The evaluator's tests use tiny fixtures only to verify metric and plot generation, not to claim model performance.
